# 模型接入规格

## Purpose

提供与大模型服务对接的统一接入能力，兼容 OpenAI 风格的对话补全接口，支持运行时配置模型端点与凭据，并支持思考与非思考两种输出模式，以适配内网自托管推理服务与未来的本地模型服务。

## Requirements

### Requirement: OpenAI 兼容端点接入
系统 SHALL 通过可配置的 base URL、模型名与 api key 对接 OpenAI 兼容的 Chat Completions 端点，MUST NOT 将端点地址或模型名写死于代码；OpenAI、Ollama 和自定义供应商均使用这一协议。本次不要求 MindIE 专项验证、供应商原生 API 或 ReAct 降级。

#### Scenario: 连接内网推理服务
- **WHEN** 用户配置了内网 OpenAI 兼容端点的 base URL、模型名与 api key
- **THEN** 系统使用该配置向端点发起对话请求并获取响应，不以供应商品牌作为额外前置验证条件

#### Scenario: 端点不可达或返回错误
- **WHEN** 配置的端点不可达或返回错误状态
- **THEN** 系统向用户报告明确的连接或调用错误，不静默失败；仅明确上下文超限时按 agent-context 规格尝试受控恢复

### Requirement: 模型配置管理
系统 SHALL 允许用户管理多个模型配置并指定当前生效配置。零配置（无任何模型配置）是合法的初始态。供应商 MUST 由下拉框选择：空白“请选择”、OpenAI、Ollama、其他；空白不可保存，其他必须填写非空自定义名称。选择器不得擅自覆盖已填写的地址、模型名或凭据。

#### Scenario: 新增并切换模型配置
- **WHEN** 用户新增一个有效模型配置并将其设为当前生效
- **THEN** 系统后续新任务使用该配置，已有运行中的任务保持其开始时的模型及预算快照

#### Scenario: 删除生效中的模型配置
- **WHEN** 用户删除当前生效的配置（包括仅剩的最后一条）
- **THEN** 系统删除该配置及其凭据并同步清除生效指针，回到零配置初始态；后续 AI 请求收到「尚无生效的模型配置」的可读引导，界面展示缺配置提示，不静默失败

#### Scenario: 编辑模型配置
- **WHEN** 用户修改当前生效配置的模型名或端点并保存
- **THEN** 系统后续新任务使用更新后的配置，编辑时未提交新密钥不清空既有密钥

#### Scenario: 空白或自定义供应商
- **WHEN** 用户选择空白项，或选择其他但没有输入名称
- **THEN** 前后端均拒绝保存并展示字段错误；选择其他并填写名称时保存实际名称而非“其他”占位值

#### Scenario: 编辑旧版自定义值
- **WHEN** 用户编辑供应商不是预置项的既有配置
- **THEN** 界面选中其他并完整回填原名称，不因不在选项中而丢失或改写配置

### Requirement: 思考与非思考双模式

系统 SHALL 支持思考模式与非思考模式两种输出方式；在思考模式下 MUST 能获取并区分模型的"思考过程"与"最终回答"，并允许用户选择默认模式。

#### Scenario: 思考模式返回思考过程

- **WHEN** 以思考模式发起请求且模型返回思考过程
- **THEN** 系统将"思考过程"与"最终回答"分别标识，供界面区分展示

#### Scenario: 非思考模式

- **WHEN** 以非思考模式发起请求
- **THEN** 系统仅获取并使用模型的最终回答

#### Scenario: 内联思考标签分流

- **WHEN** 思考模式下模型把思考过程以内联开闭标签的形式混排在正文中输出（而非独立字段）
- **THEN** 系统将标签内文本归入思考通道、标签外归入回答通道，标签字符本身不展示给用户；流式分片截断标签时不得泄漏碎片；非思考模式下原样透传不解析

### Requirement: 流式响应

系统 SHALL 支持以流式方式接收模型输出，并在生成过程中逐步向前端推送增量内容。

#### Scenario: 流式输出增量展示

- **WHEN** 模型以流式返回回答
- **THEN** 系统逐步向前端推送内容增量，而非等待完整响应后再一次性返回

### Requirement: 模型容量与输出预留配置
系统 SHALL 为每条模型配置提供上下文容量和最大输出预留的正整数 token 设置，缺省采用明确标注的保守估算值，允许用户依据实际部署修正。输出预留及安全余量后必须存在可用输入预算；修改配置不得影响在途任务。

#### Scenario: 配置不合理的预算
- **WHEN** 输出预留加安全余量已占满上下文容量，或填写非正整数
- **THEN** 系统拒绝保存并解释容量、输入与输出的关系

#### Scenario: 未知模型使用缺省容量
- **WHEN** 自定义模型没有可靠的容量声明
- **THEN** 系统使用界面明确显示的保守缺省值和估算方式，并允许用户修改，不把估算宣称为已探测的真实窗口

### Requirement: 显式协议扩展
系统 SHALL 将供应商展示名称与请求扩展能力分开，默认只发送通用协议字段；思考模式额外参数仅在配置明确启用相应扩展时发送，MUST NOT 因任意自定义名称就自动注入私有字段。既有配置迁移须保留已使用的请求行为并显式展示扩展选择。

#### Scenario: 通用端点拒绝未知字段
- **WHEN** 用户选择自定义供应商但没有启用思考请求扩展
- **THEN** 请求不包含根据名称猜测的私有开关，仍按既有思考/非思考展示规则处理端点实际返回内容
