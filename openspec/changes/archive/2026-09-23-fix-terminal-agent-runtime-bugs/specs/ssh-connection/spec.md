## MODIFIED Requirements

### Requirement: 远端终端尺寸同步
系统 SHALL 将每个可见终端的行列变化传递到所属远端 PTY，支持窗口缩放及从后台 tab 恢复显示；终端首次连接建立、以及前端终端实例（重）挂载或采纳既有会话时，MUST 主动补发一次当前真实行列——不得依赖用户手动缩放窗口才触发同步（远端 PTY 停留在默认 80x24 而本地按实际尺寸排版时，readline 类程序的方向键历史回读会跨行重排、渲染全乱）；尺寸变化不得影响其他连接，隐藏实例不得被发送零尺寸。

#### Scenario: 首连即同步真实尺寸
- **WHEN** 用户新建连接进入终端且从未手动改变窗口大小
- **THEN** 远端 PTY 的行列与本地可见终端一致（远端 `stty size` 可核对），切回 Shell 模式按上/下方向键调取历史命令时光标重排正常、终端渲染不出现叠行错乱

#### Scenario: 调整窗口或切回终端
- **WHEN** 终端窗口大小变化或后台 tab 重新显示
- **THEN** 该实例使用当前有效行列调整远端 PTY，top/vim 正确重排，隐藏实例不被发送零尺寸
