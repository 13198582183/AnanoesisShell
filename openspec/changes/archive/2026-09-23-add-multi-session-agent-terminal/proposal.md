# 多连接统一智能终端与 SFTP 变更提案

## Why

现有 Web MVP 已能连接 Linux 并进行 AI 运维，但单工作区、独立 Shell/Agent 面板、全局单槽审批和全量历史加载限制了日常使用。需要将其演进为可同时操作多个独立连接的统一智能终端，并补齐双向 SFTP、历史清理及模型上下文超限保护。

## What Changes

- 每次连接创建独立顶层 tab；同一服务器允许重复连接，各实例的 PTY、工作目录、对话、审批及传输状态隔离。
- Shell/Agent 成为同一终端内的两种输入模式，命令输出、AI 解释和审批卡片在同一工作区连续展示；通过持久 Shell 集成共享实际工作目录和环境，不以独立 exec 的同屏展示冒充共享执行环境。
- 将审批改为命令流内嵌卡片，提供执行、修改、拒绝，增加版本校验、停止/接管和后台 tab 提示，防止错误连接或旧批准执行。
- 保持每次模型调用最多选择最近 60 条数据库消息记录，包含工具消息；超出部分仅不进入上下文，数据库历史不自动删除。加入 token 预算、完整工具调用组裁剪、长结果限量及最多一次上下文超限恢复，禁止重放已执行工具。
- 增加按服务器/连接查看历史、消息分段加载、单条及批量删除；删除消息不连带删除审批审计，执行中的对话不得删除。
- 模型供应商改为下拉框：空白仅作“请选择”占位，OpenAI、Ollama、其他；选择其他时输入自定义名称。所有配置使用 OpenAI 兼容 Chat Completions 协议，不再推进 MindIE 专项探针或 ReAct 降级项目。
- **本次包含 SFTP**：远端目录浏览、本地文件上传到 Linux、远端文件下载到本地电脑，具备队列、进度、取消、覆盖确认与显式失败反馈；不要求用户预装命令行 SFTP 工具。
- **BREAKING**：AI 请求、审批、终端及传输从 host 级定位改为连接实例与运行实例绑定，前后端契约须同步发布；会话/消息列表改为有界分页；PTY 合流输出不再承诺 AI 命令可区分 stdout/stderr。
- **BREAKING**：目标连接关闭后其历史默认只读；再次连接相同服务器不会复用历史对话的执行权。Shell 集成不可用时保留人工终端与 SFTP，明确禁用自动命令执行，不隐式回退独立 exec。

## Capabilities

### New Capabilities

- `terminal-workspace`：独立连接 tab、统一终端呈现、输入所有权、连接归属与停止/关闭生命周期。
- `conversation-management`：有界历史查询、旧对话只读和手动删除，消息、运行状态及审计一致性。
- `agent-context`：每次调用的 60 条记录窗口、token 预算、工具消息完整性与无副作用重放的超限恢复。
- `sftp-transfer`：绑定连接实例的 Linux 目录浏览、文件上传/下载、进度与取消、路径及覆盖保护。

### Modified Capabilities

- `ssh-connection`：扩展多实例连接生命周期、同一持久 PTY 执行与尺寸同步，保留既有认证和交互场景。
- `ai-agent`：同一连接内共享 Shell/Agent 操作上下文，绑定执行目标，保留工具分级、手动执行及透明性。
- `command-approval`：内嵌审批、修改后的再次确认、连接/运行/命令版本绑定、执行结果未知与审计保护。
- `model-provider`：供应商选择器、统一兼容协议、显式思考扩展、可配置上下文及输出预算。

## Impact

- 前端：拆分 `frontend/src/views/TerminalView.vue` 的工作区、终端时间线、Agent 输入、历史面板、审批及文件传输职责；调整 App、路由、Pinia、WS 类型与生成客户端。
- 后端：调整 SSH 会话资源所有权、PTY 集成与输入调度、AI 回合和审批；新增上下文构建、对话管理及 SFTP 服务。
- 契约与数据库：修订 `contract/openapi.yaml`、`contract/asyncapi.yaml` 和追溯表；使用新的 Flyway 迁移追加连接绑定、运行/命令账本及审批版本等数据，禁止重写 V1 或删除既有聊天。
- 技术栈维持 Vue3/TypeScript/xterm.js、Spring Boot/Spring AI/sshj/SQLite；研究借鉴 token 裁剪和工具消息配对模式，不引入 LangChain、向量库或供应商专属会话 API。
- 本轮仅创建规划工件，不编辑业务代码、主规格、既有归档或规则，不提交/推送，不执行 apply。
- 产品范围仍为 Linux 远端、Windows 7/10/11 最终客户端。当前交付形态为 Web，上传用文件选择、下载用浏览器保存机制，不依赖 File System Access API；桌面安装器及三系统兼容认证不在本次范围。
- 本次不包含：SFTP 目录递归/断点续传、远程编辑与版本回滚、AI 自动发起本地文件传输、分屏、跳板/端口转发、主密码回退、完整发布安全整改。现存主机指纹与审计敏感信息风险不因本提案被视为解决，仍是正式发布门禁。
